# Remotion MV 分阶段执行提示词

适用于本次手机上 Claude Code 的后续任务。原始音频和 LRC 需要本人先导入；这些文字不会自动解除安卓权限或保证 Remotion 能在手机完成渲染。

## 阶段 A：只导入素材

```text
先停止扫描共享存储、尝试 content 系统命令和寻找 root。
当前已知问题是 Claw 无法读取共享存储中的 MP3 和 LRC。

请启动本仓库 scripts/upload-files.cjs，目标目录为 ~/remotion-mv，
仅监听 127.0.0.1。把带令牌的浏览器地址告诉我，后台日志保存到私有目录。
等待我在同一手机浏览器中选择文件上传，不自动运行上传文件，不覆盖已有素材。

上传完成后，确认两份文件非空且内容可读，检查 LRC 时间戳格式。
此阶段不要安装 Remotion 或开始视频制作。
```

## 阶段 B：验证渲染环境

```text
素材已经上传。请检查 ~/remotion-mv 中真实文件，而不是再次扫描共享存储。
用 command -v 检查 ffmpeg、ffprobe、浏览器等依赖，不要求 which 存在。
检查当前 Node、平台和 Remotion 版本兼容性，先确定可运行的渲染方案。

不要把桌面 Linux 程序与 Android 兼容性混为一谈，也不要自动升级已经能运行的
OpenClaw/Claude Code。若原生渲染不兼容，输出具体失败命令、错误和可迁移项目方案。

若环境可用，先创建 5–10 秒小样，真实验证音频、字幕、中文字体和导出文件可播放。
只有小样通过后才进行全片渲染。
```

## 阶段 C：制作约三分钟成片

```text
请用已经验证可读的 MP3 和 LRC，基于 Remotion 制作约三分钟的歌词 MV。
先测量音频真实时长，说明本次采用的片段范围，不虚构歌词或时间戳。
在需要创作决定的地方自主选择连贯的视觉方向，场景有变化、有叙事，
避免全片只是同一背景加滚动字幕。字幕按 LRC 同步，中文清晰可读。

工程、素材引用和所有导出输出都放在指定项目目录内。
先验证若干关键帧和短片，再渲染全片。结果必须附实际 MP4 路径、大小、时长、
分辨率、帧率和音频验证结果，不得用“计划完成”或“预期输出”替代真实文件。

如果出现不可解决的环境阻塞，报告具体错误和已完成文件，不在同一个权限错误上
无限重试，也不谎称视频已经生成。
```
