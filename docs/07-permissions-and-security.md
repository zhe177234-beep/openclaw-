# 权限、脱敏与自动执行

## 两层权限不能混淆

| 权限层 | 控制什么 | 不能做什么 |
| --- | --- | --- |
| Claude Code 工具审批 | Bash、编辑等操作是否先询问用户 | 无法给安卓 App 增加存储权限 |
| 安卓 App 文件权限 | App 能读取/写入哪些目录和 URI | “所有文件访问”仍不等于其他 App 私有数据或系统全盘权限 |

当前 Claw 项目权限声明未包含 `MANAGE_EXTERNAL_STORAGE`，本次共享存储访问失败与此背景相符。普通终端命令不能凭空授予未声明的权限。

若想保留 Claw 并长期直接读写 Music/Download，需要 App 正式支持文件选择授权，或重新构建具备所需存储权限/授权入口的 APK。自编译 APK 与原签名不同可能无法覆盖安装；先备份、设计迁移，不要直接卸载原 App。

另一种方案是在实际 Termux App 中授权并运行工具：

```bash
termux-setup-storage
```

**只能在 Termux 中执行并授权，不会授权现有 Claw。** 不同安卓/Termux发行版本的授权界面可能不同，按官方文档检查；本对话没有完成迁移。读取共享音乐和歌词不需要以 Root 为首选方案。

## Claude Code 减少逐项确认

在 Claude Code 内 `/exit`，回到 shell 后：

```bash
claude --dangerously-skip-permissions --continue
```

新会话：

```bash
claude --dangerously-skip-permissions
```

这些参数需要实际启动器转发 `"$@"`。如果你没有安装 `claude` 包装命令，可使用：

```bash
bash scripts/start-claude-scnet.sh --dangerously-skip-permissions --continue
```

该模式会跳过普通工具操作的权限确认，包括修改、删除文件和执行命令；适用于已备份、范围清楚且内容可信的项目。它不解除 Android 沙箱、不提供 Root，也不保证模型遇到必要信息缺失时绝不提问。组织策略、hooks 和某些明确限制仍可能阻止操作。

可以配合任务约束：

```text
请在指定项目目录内自主完成任务，常规实现细节自行决定。
持续执行并验证实际结果；只有缺少必要素材、凭据或遇到无法解决的阻塞时才向我提问。
不要把预期输出当作实际输出；不要在同一权限错误上无限重复命令。
```

本仓库没有默认开启全局 bypass，也没有改写用户启动文件。普通自动接受编辑与跳过所有工具审批不是同一种模式。

## 凭据与公开仓库

本仓库不收录：

- SCNet API Key、其他平台密钥、OAuth Token；
- 设备码、二维码、有效授权链接；
- 微信 user/bot ID、上下文令牌、会话数据库；
- 手机真实 `.env`、`key.env`、`.claude`、`.openclaw`；
- 未脱敏日志、手机截图、原始聊天导出和私人音频/照片。

`.gitignore` 只是防误提交，不是秘密保险箱。发布前仍要审核 `git diff`、追踪文件和历史。已经泄露的密钥需到对应平台撤销/轮换，不能只在最后一个提交里删掉。

使用浏览器上传服务时只监听本机回环地址，带临时令牌，不启用目录浏览、不自动执行文件。上传完成后停止服务，不将带令牌的地址发到公共场合。

## 对“手机 CPU”的准确描述

手机 CPU 用于 Node、网关、文件处理、命令和可能可用的本地渲染。当前 GPT、SCNet DeepSeek 与 OpenAI 绘图由远端服务处理。只有真实配置并验证本地模型推理，才能宣称模型本身在手机离线运行；本次没有该证据。
